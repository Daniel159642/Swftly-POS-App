# Email Template Generator

How to open and use the TLED email template generator.

## Opening the HTML file

1. **From Finder:** Double-click `index.html` in the `tools/email-template-generator` folder. It will open in your default browser.

2. **From terminal:**
   ```bash
   open tools/email-template-generator/index.html
   ```

3. **From VS Code/Cursor:** Right-click `index.html` and choose "Open with Live Server" (if you have the Live Server extension), or right-click and "Reveal in Finder" and double-click the file.

4. **Direct path:** Open your browser and go to:
   ```
   file:///Users/daniellopez/POS FR/pos/tools/email-template-generator/index.html
   ```

## Usage

- Edit the body text and title on the right panel.
- Use the preset buttons for quick follow-up templates.
- Choose sender (Daniel Budnyatsky or Daniel Lopez).
- Click **Copy for Gmail** to copy the formatted email.
- Paste into Gmail compose — the HTML will render with buttons, footer, and styling.
